# M3 공통 관측·명령 경계

`post-m1-policy-io-v1`은 [M2의 관측·행동 규약](../m2/learning-io.md)을 Lite와 ROS의 단일 구현으로 연결한다. 20 Hz 제어 타이머는 10 Hz 센서의 마지막 네 획득 시각을 오래된 순서로 사용한다. 레이저 데이터는 base frame의 72개 거리 값으로 재표본화하고 8 m로 정규화한다. 경로 투영으로 계산한 상대 목표·속도·경로 특징을 이어 붙이면 float32 값 296개다.

| 상황 | 처리 |
|---|---|
| 스캔 사이의 제어 틱 | 이전 네 프레임을 재사용하고 최신 위치·속도·경로로 나머지 특성을 계산 |
| 같은 스캔 또는 순서가 바뀐 스캔 | 획득 시각이 새로워질 때까지 무시 |
| 스캔 전체 손실, 잘못된 각도 또는 미래 시각 | 해당 입력을 폐기하고 네 획득이 회복될 때까지 정책 명령 보류 |
| clock 역행, 센서 프레임 변경, 목표 변경 | 해당 시점 이전의 스캔 이력을 비우고 다시 수집 |
| 같은 목표의 경로 갱신 | 새 경로로 투영하면서 유효한 스캔 이력 재사용 |
| 목표 경로 없음, odometry 또는 스캔이 0.5초보다 오래됨 | 정책 입력 보류 |

정상 행동은 `[-1, 1]`로 자른 뒤 전진 속도 0–1.5 m/s와 요 속도 ±1.5 rad/s로 변환한다. 제한 명령은 현재 측정 속도에서 시작해 50 ms 동안 선형 가속 1 m/s², 감속 2 m/s², 각가속도 1.5 rad/s²를 적용한 결과다. 잘못된 행동 또는 25 ms 추론 제한 초과의 명령은 즉시 물리적 영점이다. 실행기는 정규화 행동, 물리 목표, 가감속 제한 명령과 실제 발행 명령을 각각 확인할 수 있다.

## 기록과 재생

재생용 JSONL에 원시 LaserScan과 획득 시각, 적용된 위치·속도와 경로, 목표·경로 식별자, 네 스캔 시각, 관측 텐서와 물리 명령을 입력 순서대로 기록한다. 기록에서 Lite 공통 함수를 다시 실행해 관측 최대 절대 오차 1e−7 이하, 동일한 스캔 시각과 명령을 요구한다. 번들을 지정하면 NumPy 추론의 행동 오차도 1e−5 이하인지 확인한다.

```sh
PYTHONPATH=packages/amr_lite python -m amr_lite.learning.stamped_replay TRACE.jsonl --bundle BUNDLE_DIR
```

공통 회귀 테스트는 움직이는 장애물의 동일한 원시 획득을 ROS형 입력과 Lite형 bin 입력에 주입한다. 두 쪽에서 네 프레임 모두 달라지고, 중간 20 Hz 틱에서는 그 네 시각이 유지된다. 같은 시각·순서 뒤바뀜·stale·미래 시각·clock reset·경로 교체·잘못된 행동·추론 제한 초과와 기록 변조도 검사한다.

# M4 · 창고 운송 정책 개발

M4에서는 M3의 4m 정적 Gazebo 진단을 마친 정책을 출발점으로 삼아, 학습 방법을 바꿨을 때 Lite 운송 임무를 더 자주 완주하는지 평가한다. 로봇 한 대가 120초 안에 목표의 0.4m 이내에 도착하고 접촉이 없어야 기본 운송 임무를 성공으로 센다.

## 후보 판정

**개발 실험 9회와 평가 312회를 마쳤으며 M5에 넘길 정책 후보는 보류했다.** 2026-11-26 02:47~02:52 KST에 로컬 CPU에서 총 1,769,472전이를 학습했다. 당시 코드 리비전은 `2a3df12`다. 27개 단계 체크포인트와 9개 최종 actor의 해시를 검산했다. 최종 actor에서 SB3와 NumPy 행동의 최대 절대차는 2.39×10⁻⁷ 이하였다. [학습별 설정과 실행 증거](../../experiments/m4/training.json)

| 구성 | 전체 무충돌 완료 | 동적 무충돌 완료 | 전체 접촉 | 정적 시간 초과 | 판정 |
|---|---:|---:|---:|---:|---|
| M3 비교 모델 | 0/16 | 0/12 | 5/16 (31.25%) | 2/4 (50.0%) | 기준 |
| 전체 구성 | 12/48 | 8/36 | 6/48 (12.5%) | 8/12 (66.7%) | 정적 시간 초과 증가 |
| 이력 제거 | 6/48 | 4/36 | 8/48 (16.7%) | 10/12 (83.3%) | 정적 시간 초과 증가 |
| 환경 변동 제거 | 20/48 | 9/36 | 16/48 (33.3%) | 0/12 (0%) | 전체 접촉률 증가 |

기본 평가는 208회, 복수 장애물·경로 복귀 추가 진단은 104회였다. 측정 불능은 0회였다. M3는 기존 actor 하나, M4 구성별 표는 세 학습 seed의 합계다. 같은 임무와 센서 조건을 여러 번 사용했으며, 312회 모두 개발 분할에서 수행했다. 모든 구성에서 동적 완료율이 0인 학습 seed가 하나 이상이었다. [시행별 기록](../../experiments/m4/development/) · [seed별 집계와 짝 비교](../../experiments/m4/development-summary.json)

전체 구성의 동적 완료 8회는 모두 seed 19에서 나왔다. 안전 기능을 끄고 같은 세 actor를 재생하자 전체 접촉이 6/48회에서 22/48회로 늘었다. 환경 변동 제거 구성은 정적 운송 11/12회를 완주했으나, 정면 접근에서는 9/12회 충돌했다. 특히 실측 프로파일의 정면 접근 6회가 모두 충돌했다. 다음 개발 실험의 우선순위는 정적 종점에서 멈춘 경우와 실측 지연·잡음 조건에서의 정면 충돌을 나누어 재현하는 것이다.

[M5 운용 준비](../m5/operations.md)에서는 목표 취소·정지·DWA 전환·재계획을 오프라인 콜백으로 검증했다. M5 반복 운송·고장 주입·2대 호환과 M6의 미사용 임무 평가는 후속 단계로 남아 있다.

## M3 실패를 재현한 결과

M3 정적·횡단·정면 접근의 원본 기록에서는 로봇이 목표에 가장 가까워졌을 때도 1.5m/s로 주행 중이었다. 경로 끝에 투영됐을 때 진척 보상은 100에 도달했지만, 로봇과 목표 사이에는 약 0.87m가 남았다. 일시 차단에서는 로봇이 목표 방향에 직각으로 서서 출발했고, 장애물을 제거한 시점부터 종료까지 2,001개 제어 주기 모두에서 보호 기능이 개입했다. [원본 로그에서 재계산한 지표](../../experiments/m4/m3-failures.json)

## 이번 실험의 변경점

- 경로를 따라 남은 거리에 로봇과 경로 투영점의 거리를 더해 진척 보상을 계산했다. 경로가 교체되면 새 경로에서 거리 기준을 다시 잡는다. 운송 임무의 도착 반경과 시간 제한은 M2 규약을 따른다.
- 학습 전용 장면 8개를 추가했다. 짧은 주행·방향 전환·경로 복귀에서 시작해 횡단·정면 접근, 복수 장애물·차단 해제와 기존 운송 임무를 연습한다. 센서와 충돌 계산에 같은 장애물 궤적을 사용한다. [장면 정의](../../experiments/m4/curriculum.json) · [환경 설정과 검증](../../experiments/m4/environment-freeze.json)
- SB3 PPO를 seed 7·19·31에서 각각 학습했다. 전체 구성과 두 제거 실험 모두 4개 워커에서 단계당 65,536전이씩 학습한다. 이력 제거는 최신 스캔을 네 슬롯에 복제한다. 환경 변동 제거는 학습 중 명목 센서·구동 설정을 사용한다. 보호 기능의 기여는 전체 구성의 같은 가중치로 평가한다. [사전 지표와 후보 조건](protocol.md)

## 실행 방법

저장소 루트에서 M3와 동일한 Python 환경을 사용한다. 필요한 버전은 SB3 2.4.1, Gymnasium 1.0.0이며 실행 환경에 맞춰 동시 학습 수를 조정할 수 있다. 원본 로그 요약은 모델을 재학습하지 않고 검산할 수 있다.

```sh
export PYTHONPATH="$PWD/packages/amr_lite"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 MPLBACKEND=Agg
python scripts/m4/diagnose_m3.py /path/to/train-65536-r2
python scripts/m4/train_matrix.py --jobs 3 --out .cowork/m4/runs
scripts/m4/evaluate_matrix.sh /path/to/train-65536-r2/bundle .cowork/m4/runs .cowork/m4/new-scores
```
